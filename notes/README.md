# notes/

Working notes that are not code, not reports and not the worklog.

* `briefs/` — self-contained task briefs handed to Codex (`docs/codex.md`). One file per
  invocation, numbered to match `experiments/runs/codex/NN-*.jsonl` and the review it produced:
  `codex-01-indep-oracle.md` → `tests/oracle/indep_sim.py`;
  `codex-02-noise-review.md` → `reviews/002b-codex-noise-adversarial.md`;
  `codex-03-session2-review.md` → `reviews/003-session2.md`.
  A brief must stand alone: conventions, paths, deliverable format, sandbox mode, and what the
  reviewer should try to break.

Session narrative goes in `worklog/`, state in `STATE.md`, decisions the paper leaves open in
`PLAN.md §0`.
